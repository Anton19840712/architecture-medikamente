# architecture-medikamente - sprint 10 practice

Подготовлен комплект артефактов по всем заданиям `Task1`-`Task6` для кейса "Медикаменте".

## Структура

- `Task1` - анализ безопасности, DFD, проблемы, защита и теги данных
- `Task2` - контекстная C4-диаграмма целевой архитектуры
- `Task3` - классификация данных и стратегия шифрования
- `Task4` - диаграмма Исикавы и отчёт по bottlenecks
- `Task5` - cutover-план миграции
- `Task6` - C2-диаграмма движка классификации данных

Все текстовые диаграммы подготовлены в Markdown + Mermaid, а для `Task4` дополнительно создан файл `draw.io`.
