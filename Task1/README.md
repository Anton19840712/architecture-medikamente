# Task1 — Анализ безопасности системы

## Содержимое директории

- `as-is-security-analysis.md` — процессы, DFD (Mermaid), аудит текущих мер защиты, рекомендации.
- `problem-zones.md` — список проблемных зон с приоритетами.
- `data-protection-register.md` — реестр данных, способы защиты, модель тегирования, инструменты.
- `152fz-compliance-analysis.md` — маппинг нарушений на статьи 152-ФЗ с приоритетами устранения.
- `dfd-patient-registration.drawio` — DFD (нотация Gane & Sarson): запись пациента на приём (As-Is).
- `dfd-medical-record.drawio` — DFD (нотация Gane & Sarson): ведение медицинской карты (As-Is).
- `dfd-payment.drawio` — DFD (нотация Gane & Sarson): платёж и бухгалтерский учёт (As-Is).

## О диаграммах DFD

Диаграммы выполнены в нотации Gane & Sarson и открываются в [app.diagrams.net](https://app.diagrams.net):

| Символ | Значение |
|---|---|
| Прямоугольник (серый, цельный) | Внешняя сущность (Entity) |
| Прямоугольник (синий, разделённый) | Процесс (Process) |
| Прямоугольник (жёлтый, разделённый) | Хранилище данных (Data Store) |
| Серая стрелка | Поток данных |
| Красная стрелка | Поток данных с риском конфиденциальности |

Целевые меры защиты (To-Be) описаны в `as-is-security-analysis.md`.
