# Task1 - Анализ безопасности системы

В директории собраны артефакты по анализу текущего состояния `As-Is`:

- `as-is-security-analysis.md` - процессы, DFD, аудит текущих мер защиты и рекомендации.
- `problem-zones.md` - список проблемных зон и приоритет улучшений.
- `data-protection-register.md` - перечень данных, способы защиты и модель тегирования.

Диаграммы потоков данных приведены в Mermaid, по одному процессу на диаграмму. Для каждого процесса показаны:

- текущее движение данных;
- ключевые риски;
- целевые меры защиты по потоку.
